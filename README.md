

## Запуск

1. Установи Node.js 18+.
2. В этой папке выполни `npm install`.
3. Скопируй `.env.example` в `.env`.
5. Запусти `npm start`.
6. Открой `http://localhost:3000`.

API-ключ намеренно не находится в HTML: браузер не должен его видеть.


- Модель по умолчанию: `openai/gpt-oss-120b`.
- Характер: обычный / грубоватый / почтительный.
- Отдельная настройка разрешения мата.
- Дополнительное описание характера.
- История чатов сохраняется в Firebase Firestore в аккаунте пользователя.
- Новый чат и список прошлых чатов.
